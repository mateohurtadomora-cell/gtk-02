Programa Avanzado en Desarrollo de Aplicaciones XML y Wireless

La programación en XML, al operarse como un lenguaje de definición de lenguajes, se está constituyendo como uno de los stándares de uso imprescindible en las nuevas tecnologías de la información. Su relevante auge va unido ineludiblemente con el desarrollo de las nuevas tecnologías móviles para las cuales se hace imprescindible el uso del lenguaje XML.

Este programa esta diseñado para atender a las necesidades específicas que, en cuanto a tecnologías móviles, el mercado actualmente plantea. Aunar, por un lado, el desarrollo de aplicaciones XML para posteriormente, sobre esos conocimientos, adentrarse en el desarrollo de aplicaciones para wireless y dispositivos móviles, lo convierte en un programa completo y específico dirigido a profesionales con experiencia que deseen estar al día en sistemas de gestión y programación más complejos de bases de datos.


Dirigido a:

Programadores, diseñadores, webmasters, administradores y, en general, profesionales IT con experiencia en programación Java o en cualquier otro lenguaje de programación orientada a objetos.


Requisitos previos de conocimiento

Es necesario tener conocimientos de programación en JAVA, o conocer programación orientada a objetos.

En el caso de que el solicitante, tenga carencias en cuanto a programación JAVA, deberá tomar, previa e independientemente a éste, un Curso Preparatorio, (8 horas) de esta temática para asentar los conocimientos necesarios que le permitan incorporarse a este Programa.


Programa

Un Programa único que consta de dos cursos específicos.


Curso 1: Desarrollo de Aplicaciones XML

El XML aporta una sintaxis standard para compartir e intercambiar datos con independencia de la plataforma. XML se usa mayoritariamente para aplicaciones con gran demanda de datos y peticiones desplegadas en web o en aplicaciones wireless. Partiendo de un conocimiento previo en programación orientada a objetos, el curso se adentrará en el Document Object Model (DOM), y en stándares XML como Extensible Linking Language (XLL) y Extensible Stylesheet Language (XSL). Se tratará asimismo los métodos usados para resolver cuestiones de bases de datos relacionales (como integridad referencial) en una aplicación basada en XML, y métodos de diseminación de tipos de datos XML usando Servicios Web y SOAP.

  • Definición de Servicios Web con XML
  • Integrando JSP´s con bases de datos
  • Integrando JSP´s y XML (DOM, SAX. JDOM. DOM4J, JAXB)
  • Programando SAX
  • Técnicas avanzadas JSP y XML
  • Generación de Informes a partir de datos XML
  • Evolución de los protocolos XML
  • Gestión completa de Servicios Web con XML


Curso 2: Desarrollo de Aplicaciones Wireless

Debido al auge de los dispositivos inalámbricos, el mercado está solicitando profesionales capaces de desarrollar e implementar este tipo de aplicaciones. La explosión y variedad de funcionalidades de los dispositivos inalámbricos como Blackberrys, teléfonos móviles y PDAs requiere ser capaz de desarrollar formatos de presentación de datos adaptados a diversas plataformas. Tras los conocimientos adquiridos en el curso anterior, a lo largo de este curso el estudiante aprenderá a trabajar, desarrollar e implementar aplicaciones para dispositivos inalámbricos.

  • Introducción a la tecnología móvil y al negocio de la movilidad
  • Arquitecturas y componentes J2ME
  • Container-Managed Applications
  • Patrones de arquitectura de servicios móviles
  • Técnicas avanzadas (Tacking, Autenticación, portales)
  • Email, PIM y mensajeria P2P
  • Bases de datos para dispositivos CDC
  • Bases de datos para dispositivos MDP
  • XML y servicios móviles web
  • Dispositivos móviles para localizaciones
  • Movile Security
  • J2ME desarrollo de aplicaciones para dispositivos móviles (telefonía, PDAs, pocket Pc)


Metodología

La participación y asistencia a clase del Programa Avanzado en Desarrollo de Aplicaciones XML y Wireless tiene carácter obligado.

El Programa combina las clases teóricas con un fuerte componente de prácticas de los temas tratados ( hands-on).

Como bibliografía de apoyo, el alumno deberá, asimismo, seguir determinados temas con el apoyo de uno o varios libros de texto de programación y aplicaciones ( en inglés).

En cada uno de los cursos que componen este programa, el alumno realizará un examen a mitad del mismo asi como un examen final.


Duración

80 horas. (lunes y jueves de 19:00 a 22:00 horas).

El Programa conllevará determinadas horas adicionales para trabajo en laboratorio.
